Privacy

%NG_TITLE% is a free browser game. It has no accounts, no cookies, no analytics, no tracking and no ads.

On your device

The game keeps its settings, your local best scores, the name you last used on the board and a random player ID in your browser's local storage, and a "the intro was shown" flag in session storage. Only the random player ID is ever sent: to look up your own place on today's board (the board panel does this while it is shown; the lookup is not stored) and with a run you submit. Clearing this site's data in your browser deletes all of it.

The online board (Hard only)

Only when you choose to submit a Hard run to today's board, the server stores:

  • the name you typed and, for the day's best run only, your short message;
  • the score, the hero, the run length and the view (full arena or the zoomed phone camera);
  • the replay of the run (your inputs, used to re-simulate and verify the score);
  • the random player ID from your browser (it ties your runs of a day together; it is never shown);
  • the date and time of the run.

To limit abuse, the server also counts requests per salted hash of your IP address, and submissions per player ID. Your IP address itself is not stored; these counters are deleted within two days.

Board entries are kept for 30 days and then deleted automatically. Names and messages are public on the board.

The server also keeps a short operations log (moderation actions, verification results, and hourly counts of failed access attempts to its private endpoints). It holds no personal data: no names, messages, player IDs or IP addresses. It is kept for 90 days and then deleted automatically.

Deletion

To have a name, message or run removed before then, with the date, the name on the board and what should be removed. Do not put the random player ID or anything else private into a public place. The maintainers remove the entry with the server's moderation tool. Offensive names and messages are removed without being asked.

Hosting

The game and the board run on Cloudflare (Pages, Workers and D1). Delivering a website involves processing connection data such as your IP address; the game itself adds nothing to that.
